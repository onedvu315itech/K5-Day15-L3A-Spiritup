## Đọc nhanh theo tình huống

- **"Nhóm mình chưa chắc pain có thật không"** → Mom Test (3 quy tắc, 3 phản xạ khi nghe), rồi PAIR 1.1.
- **"AI nên tự làm hay chỉ gợi ý?"** → PAIR 1.2 + [guide 2.2](../02-guide.md#b2-2) bảng mức tự động.
- **"Chọn nguyên tắc nào cho spec §4?"** → [hax-guidelines.md](hax-guidelines.md) (G10 bắt buộc) + PAIR chương 3–5.
- **"Nghĩ không ra kịch bản lỗi"** → PAIR chương 6 (bốn nguồn lỗi) + HAX Playbook.
- **"Định nghĩa 'tốt' để đo thế nào?"** → PAIR 2.3 (bảy chiều chất lượng) + [guide 2.4](../02-guide.md#b2-4).
- **"Tính chi phí khi dùng thật"** → [model-prices.md](model-prices.md) + [guide 4.2](../02-guide.md#b4-2).
- **"Đi thử với người thật"** → [guide 4.3](../02-guide.md#b4-3) + PAIR 5.1 (tín hiệu hai nghĩa: tạo lại, sửa, dừng lâu, hỏi tiếp).

Mọi tóm lược trong thư mục này là bản viết lại của BTC để dùng trong khoá; trích dẫn hay đọc sâu thì dùng bản gốc và ghi nguồn.
